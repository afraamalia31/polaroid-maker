Foto kamu

Geser foto untuk mengatur posisi crop. Tombol − dan + mengatur jumlah salinan tiap foto.

Tiap kartu bisa diunduh sebagai JPG berukuran sama dengan kartunya (300 dpi), siap dikirim ke jasa cetak. Nama file memuat jumlah salinan, misalnya kartu-02-x3.jpg berarti cetak 3 lembar. Chat Shopee hanya menerima gambar, jadi pakai tombol Bagikan atau gambar terpisah, bukan ZIP atau PDF.
